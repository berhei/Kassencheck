# Idee

Ich möchte eine Webabpplikation gehostet bei github über github pages entwickeln. Diese soll genutzt werden um die Bargeldkasse zu zählen und das Ergebnis zu überprüfen und zu dokumentieren.



- Tests sollen erstellt werden die vor dem deployment laufen und eine Anzeige in der Readme der github Projektseite sollte zeigen ob die tests erfolgreich sind.
- Responsive
- Gut auf Smartphones und Tabletts bedienbar sein. Wo sinnvoll slider oder als eingabemöglichkeit nur ein Zahlenkeyboard.
- Ergmöglichen einen Screenshot des Zählergebnisses mit den Details zu exportieren und zu versenden. (Sharesheet auf iOS etc.)
- Die Stückelung des Bargelds sind die üblichen Euro Münzen und Scheine. 10ct Münze bis 200 Euro Schein.
- Automatisches Deployment über github actions
- Readme datei des repositories sollte alles erklären was gemacht wird.
- Dokumentationssprache englisch
