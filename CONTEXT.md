# Cash Count

Terms used when counting and checking the physical cash held in a register.

## Language

**Cash register**:
The single cash holding whose entire physical contents are counted in one cash count.

**Cash count**:
One person's count of all physical cash in a single cash register at a particular time. Recording the person's name is optional.
_Avoid_: Partial count

**Counted total**:
The sum of the counted cash across all denominations in a cash count.

**Expected balance**:
An optional reference amount against which the counted total is compared.

**Difference**:
The counted total minus the expected balance when an expected balance is provided.

**Count record**:
An exportable account of a cash count; it is not a history stored in the application.
